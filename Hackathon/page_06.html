What Makes AI-EcoTrack Powerful

KEY FEATURES

06

AI Part ID

Llama 4 Scout identifies part type, material, and hazard level instantly from a single photo, eliminating manual sorting errors.

Digital Passport

Every scan generates a Digital Product Passport (DPP) ensuring full material traceability from bin to recycling center.

WRI Score

Calculates Weighted Recyclability Index automatically, assigning an A/B/C grade and estimating USD recovery value.

Live IoT

Real-time telemetry for fill level, toxic gas (MQ-135), CO (MQ-7), and temp/humidity streamed directly to Firestore.

Multi-key AI

Robust backend with automatic Groq API key rotation ensures the vision system never goes down due to rate limits.

Secure

Enterprise-grade security with strict Firestore rules, Admin SDK for writes, and anonymous auth for client-side reads.
