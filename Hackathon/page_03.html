Introducing AI-EcoTrack

AI-EcoTrack = Smart Bin + AI Scanner + Real-time Dashboard

Smart Bin (IoT)

Integrated sensor suite that monitors critical metrics at the source.

  • Real-time fill levels
  • Toxic gas detection
  • Temp & humidity
HARDWARE

AI Scanner

Computer vision system powered by Qwen 3.6 27B for precise ID.

  • Identifies parts
  • Detects materials
  • Flags hazards
MODEL

Digital Passport

Generates a unique digital identity for every recycled component.

  • Material composition
  • Recovery value ($)
  • Lifecycle trace
DATA

Live Dashboard

Centralized web application visualizing all system data instantly.

  • Real-time sensor graphs
  • Scan history logs
  • Alert notifications
